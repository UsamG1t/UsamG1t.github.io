# О проекте

UsamG1t.github.io — объединённая платформа проектов и материалов за моим авторством, реализованная на базе Github Pages. Здесь представлены полнотекстовые версии курсов, читаемых на ВМК МГУ (в частности, кафедре АСВК); обучающие материалы по курсам ВМК МГУ; проекты для демонстрации определённых технологий; персональные pet-проекты. Здесь также хранятся статьи и ссылки на проекты, которые заинтересовали меня и могут заинтересовать вас.
